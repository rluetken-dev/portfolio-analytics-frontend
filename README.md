This is the frontend for the Portfolio Analytics project.
It is built with React, TypeScript, and Vite.

## 🚀 Development

- Run `npm run dev` to start the dev server
- Open http://localhost:5173/ in your browser
- Hot Reload is enabled

## 📦 Tech Stack

- React 18
- TypeScript
- Vite
- npm
